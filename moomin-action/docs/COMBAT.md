# 실시간 코인 전투 — 구현 문서 (설계서 v1.0 → Unity 코드)

> 원칙: **조작 실력은 명중·회피를 정하고, 코인 확률은 명중한 공격의 위력·추가 효과를 정한다.**
> 수치 검증과 합 승률 표는 [`balance.md`](balance.md) (`python3 tools/coin_sim.py` 로 다시 생성).

## 미정 3가지 — 임시 확정값(데이터로 언제든 변경)
| 질문 | 선택 | 바꾸는 곳 |
|---|---|---|
| 코인과 공격 모션 | **혼합**: 연속 공격 스킬은 코인 1개 = 공격 1번(`CoinMode.PerHit`), 특수 스킬은 한 동작에 코인 여러 개(`SingleMotion`) | `SkillData.mode`, `hitTimes` |
| 클래시(합) | **위력 비교 + 방어 타이밍 둘 다**: 공격끼리 부딪히면 합, 방어 중 맞으면 방어 코인으로 합, 누른 직후 0.2초는 패링(기본 위력 +8) | `ClashManager`, `CombatManager.parryWindow` |
| 적 AI | **일반 적 = 패턴형, 보스 = 상황 대응형**(웨이브 3마다 보스) | `EnemyAI.behavior`, `Choose()` |

## 수식
- 앞면 확률 `Pr(H) = Clamp(0.5 + S/100, 0.05, 0.95)`, S = 정신력(-45~+45)
- 위력 `P = B + H×C`. 연속 공격은 타격마다 **그때까지의 앞면 누적**으로 계산(Pᵢ = B + Hᵢ×C)
- 피해 `D = P × M × R` → 반올림, 최소 1. M = 스킬 배율 × 무기 배율 × 정신력 보정(집중 1.1), R = 대상 보정(경직 중 1.5, 붕괴 상태로 맞을 때 1.25)
- 코인은 **타격 시점에 하나씩** 확정, 빗나가도 소모. 던질 때의 정신력으로 판정하고 이후에 바뀌지 않음

## 합(림버스 방식)
1. 플레이어 타격과 적 공격이 겹치면 발동: 내 타격 순간에 적이 공격 판정 중이거나, 적 공격이 닿는 순간 내 다음 타격이 0.2초 안이면 그 타격을 당겨서 합
2. 매 라운드 양쪽이 **남은 코인 전부**를 던져 위력 비교 → 진 쪽 코인 1개 파괴, 동점은 재대결(최대 12라운드, 넘으면 무승부)
3. 결과
   - **승리**: 정신력 +5, 적 경직 1.2초(받는 피해 ×1.5 = 반격 기회), 내 스킬은 **남은 코인으로** 계속(파괴된 코인의 타격은 사라짐)
   - **패배**: 정신력 -5, 내 스킬 중단·경직, 적이 **남은 코인 수만큼** 연타
   - **무승부**: 양쪽 공격 무효, 짧은 회복
4. 방어 합: 방어 코인(기본 6, +4×2), 패링이면 기본 +8. 이기면 무피해(패링이면 적 경직), 지면 적의 남은 코인이 **절반 피해**로 들어옴. 보라색 경고 공격은 방어 불가
5. 연출은 히트스톱(0.08~0.15초) + 화면 위쪽 합 패널(라운드를 0.18초 간격으로 표시). 전투 흐름은 멈추지 않음

## 적 공격 처리 순서(플레이어가 맞는 순간)
회피 무적이면 **회피 성공(정신력 +1)** → 내 타격이 곧 나가면 **합** → 앞쪽 방어 중이면 **방어 합** → 아니면 **일방 공격**(적 코인마다 한 번씩 타격, 0.14초 간격, 도중에 구르면 남은 타격 회피)

## 데이터로 바꾸기
- 메뉴 **Moomin ▸ 스킬 데이터 에셋 만들기** → `Assets/Resources/Skills/*.asset` 생성, 인스펙터에서 수치를 고치면 코드 수정 없이 반영
- 적 공격은 적 프리팹의 `EnemyAI ▸ Attacks` 목록에서 수정
- 메뉴 **Moomin ▸ 코인 확률 검증** → 정신력별 실제 앞면 비율, 3코인 분포, 합 승률을 콘솔에 출력(설계서 9장 테스트)

## 아직 아닌 것
- Unity 에서 컴파일·플레이 테스트 전(이 저장소는 Unity 에디터 없이 작성). 문법 검사와 Python 시뮬레이션만 통과
- 애니메이션 이벤트 대신 타이머로 타격 시점을 맞춤(클립 길이와 동기화). 이벤트로 바꾸려면 클립 이벤트에서 `AttackController.ExecuteCoin()` 호출
- 코인·합 효과음 없음, 코인 이펙트는 파티클 색(금색 = 앞면)으로만 구분
