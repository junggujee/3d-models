# 바다 · 선착장 · 헤엄 · 통통배

## 어디에 있나

- **맵 구조:** 맵 바닥은 지름 약 1.2km인 정24각형 원판(z=0)이다. 마을은 성벽에, 성벽 바깥은 산맥에 둘러싸여 있어 **걸어서는 바다에 갈 수 없다**.
- **바다:** 원판 바깥 전체가 바다다(섬). 지도 남쪽 끝 꼭짓점에 **남쪽 선착장**이 있다.
- **바닷길 문:** 마을 남쪽 성벽 안쪽(지도 기준 e=40, s=123)의 나무 문 `Gate_Town` ↔ 선착장 뭍의 기둥 문 `Gate_Harbor`.
  - 문 앞에서 `F`를 누르면 화면이 어두워졌다 밝아지며 건너편으로 간다(`SceneFader.Cover`).
  - 펫도 함께 오고, 카메라는 뒤로 붙는다.
  - 웨이브 전투 중에는 쓸 수 없다.
- **선착장 안(반지름 320m):** 웨이브가 새로 시작하지 않는다. 저장 장소 이름은 "남쪽 선착장"이다.

- **좌표:** City_*.fbx와 같은 내보내기 설정(axis -Z/Y, FBX_SCALE_ALL)을 쓴다. 그래서 `World` 아래 원점에 그대로 두면 맵과 맞는다.
- **선착장 좌표계:** 원판 중심 C(-50.0, 28.3), 꼭짓점 반지름 586m, 남쪽 끝 꼭짓점 T. `u`는 바다 쪽, `v`는 옆이다.
- **해수면:** z = **-0.8**.

**바닥 높이**는 원판 가장자리에서 바깥으로 거리 d에 따라 정한다.

| d | 높이 |
|---|---|
| 0 | 0 |
| 10m | -1.2 |
| 40m | -6.3 |
| 130m | -15 |
| 450m 이상 | -30 ~ -35 |

- 여기에 물결 모양의 낮은 노이즈가 더해진다.
- 선착장 앞은 배가 다니게 골을 파서 2.2m 더 깊다.
- 바닥은 원판을 키운 고리 25개로 만든다. 선착장 양쪽 변만 촘촘하게(2.4m 간격) 나눈다.

## Unity

- **`World/Seaside.cs`:** `GameManager.Start`가 NavMesh를 굽기 전에 `Seaside.Ensure()`를 부른다. 장면에 바다가 없으면 Resources에서 만든다.
  - 바닥·충돌 상자에 MeshCollider를 붙인다.
  - `Ocean`을 설정하고 부표를 등록한다.
  - 선착장 둘레 150m를 따로 굽도록 `NavMeshBaker.Extra`에 넣는다.
  - 바닷길 문 2개를 설정한다.
  - Start에서 통통배와 어부 철썩이를 놓는다.
- **`World/Ocean.cs`** (물 알고리즘·최적화)
  - **파도:** 게르스트너 파도 4개(`World/OceanMath.cs`, 순수 C# · status_tests). 셰이더와 **같은 식**이다.
    - 파장은 22 / 13 / 8.5 / 5m이고, 기본 방향은 바다에서 물가 쪽이다.
    - 진폭 합 0.69m는 해수면과 뭍의 높이 차 0.8m보다 작아 물이 뭍으로 넘치지 않는다.
  - **수면 높이(CPU):** 알갱이가 옮겨 간 자리를 3번 되풀이해 거꾸로 찾는다(오차 2cm 미만). 헤엄·배·부표만 묻는다.
  - **얕은 곳:** 물결이 작아진다(깊이 0m → 35%, 6m 이상 → 100%). 깊이 그림은 시작할 때 한 번 굽는다(224², 선착장 둘레 640m, 바닥 충돌체에만 광선).
  - **물 메시:** 하나(동심원 고리 72 × 128칸 ≈ 9천 점, 0.8m → 1.7km)를 카메라를 따라 2m 단위로 옮긴다. 그리기는 1번이다.
    - 파도는 GPU 정점 셰이더에서 계산하고, 180~420m 밖은 물결이 0이다(먼 곳 깜빡임 방지).
  - **섬 안쪽 깊숙이(마을):** 물 메시를 끈다.
  - **쓰지 않는 것:** 반사·굴절 카메라, 카메라 깊이 텍스처, 반사 프로브. 하늘색 그라데이션 반사와 구운 깊이 그림으로 충분하다.
  - **물속:** 안개(짙은 청록, 지수 0.055)와 화면 물색 덧칠이 켜지고, 나오면 원래 안개로 돌아간다.
- **`Resources/Shaders/MoominOcean.shader`:** 기본 파이프라인과 URP 모두에서 쓴다. 조명 태그가 없는 CG 패스라 URP에서는 SRPDefaultUnlit로 그려진다.
  - **물 위:**
    - 해석 법선에 흐르는 잔물결 노멀 2장을 더한다(코드로 만든 128² 텍스처).
    - 프레넬로 하늘을 반사한다.
    - 물색은 얕은 곳 청록 → 깊은 곳 남색이고, 물마루에 속빛이 비친다.
    - 해 반짝임이 있다.
    - 거품은 물가로 밀려오는 띠와 물마루 거품 두 가지다.
    - 먼 곳은 수평선 색으로 바뀐다.
    - 물가는 투명해 모래가 비친다.
  - **물속에서 올려다보기:** 스넬 창(바로 위는 밝은 하늘, 비스듬하면 물색)이 보인다.
- **`Player/PlayerSwim.cs`**
  - **물 위:**
    - 발이 수면 아래 0.95m보다 깊어지면 헤엄을 시작한다. 바닥이 수면 아래 0.7m보다 높아지면 걸어 나간다.
    - 몸이 파도를 따라 출렁인다. 발 위치는 수면 −0.85m, 앞으로 헤엄칠 때는 눕혀서 −0.35m다.
    - WASD로 움직이고, Shift로 빨리 헤엄친다(기력 소모).
  - **잠수:**
    - `Z`로 들어가고 나온다. 바라보는 방향(위아래 포함)으로 헤엄친다.
    - `Space`는 위로, 왼쪽 `Ctrl`은 아래로. 패드는 A(잠수)와 십자 위/아래다.
    - 숨은 25초다. 다 떨어지면 초당 최대 체력의 4%가 줄어든다. 물 위에서 초당 8씩 다시 찬다.
    - 입에서 공기 방울이 나온다. 몸(모델)은 움직이는 방향으로 기운다. 수면까지 올라오면 저절로 물 위 헤엄으로 바뀐다.
  - **제한:** 헤엄·배 타기 중에는 공격·방어·구르기가 없다(`CombatManager` · `PlayerController`).
  - **숨 표시:** `UI/BreathMeter.cs`가 방울 10개로 보여 준다.
- **`World/Boat.cs`** (통통배, Rigidbody 없음)
  - **타기:** 헤엄 중에도 가까이 가서 `F`.
  - **조작:** W/S로 앞뒤(9 m/s, 뒤로 3 m/s, Shift 12 m/s), A/D로 방향(빠를수록 잘 돈다).
  - **내리기:** `F`. 다리 옆 9m 안이면 다리 위로, 아니면 바다로 풍덩 떨어진다.
  - **물에 뜨기:** 네 점의 수면 높이로 높이·앞뒤 기울기·좌우 기울기를 정한다. 빠르면 뱃머리가 들린다.
  - **부딪힘:**
    - 앞으로 구를 쏘아 다리·바위에 닿으면 튕긴다.
    - 바닥이 0.9m보다 얕으면 멈춘다.
    - 선착장에서 900m를 넘으면 되돌린다.
  - **연출:**
    - 굴뚝 연기가 "통…통…" 하고 나온다(빠를수록 자주).
    - 배 뒤에 하얀 물결이 생기고, 빠르면 뱃머리에 물보라가 인다.
    - 프로펠러가 돌고 깃발이 펄럭인다.
  - **카메라:** 배를 따라간다(9.5m, `ThirdPersonCamera.Follow/Restore`).
- **`Effects/WaterFx.cs`:** 물보라·공기 방울·연기·거품. 각각 장면당 ParticleSystem 하나에 Emit한다(SparkBurst와 같은 방식).
- **어부 철썩이:**
  - 조랭하프족 NPC에 노란 어부 모자를 머리 뼈 bindpose로 붙인다(`NpcAccessory` / `BoneAttach`, 장비와 같은 방식).
  - 초상화는 `fisher_*`다.
  - 대화(`Story/HarborStory.cs`) 메뉴는 통통배 타는 법 · 헤엄·잠수하는 법 · 바다 이야기다.

## 확인 못 한 것 (Unity 미실행)

- 물 셰이더의 실제 색·밝기(값은 머티리얼 속성으로 바꿀 수 있음). FBX 축(City와 같은 설정이라 맞을 것으로 예상).
