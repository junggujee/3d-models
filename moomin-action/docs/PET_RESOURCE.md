# 자원 · 펫 · 집 장비

## 땅콩빵 (자원 오브젝트)

- **모델:** `blender/build_peanut.py` → `Models/PeanutBread.fbx`. 사용자 사진(하얀 메모리폼 땅콩 베개)을 바탕으로 했다.
  - 크기 1.0 × 0.5 × 0.34m, 가운데가 잘록하다.
  - 엇갈린 바구니 짜임 천(`Weave_Normal`)과 아래쪽 둘레 솔기가 있다.
- **부서지는 구조:** 가운데에서 잘라 두 물체(LobeL·LobeR)로 만들었다. 자른 면은 노르스름한 메모리폼 속이다.
- **생성 자리:**
  - 산 정상 5곳: `SpawnPoints.json`의 peaks 12곳 중 무작위.
  - 자연: 낮은 확률(15%).
  - 걸을 수 없는 꼭대기라면 가장 가까운 걸을 수 있는 곳(NavMesh)으로 옮긴다.
- **부수기(`World/ResourceNode.cs`):**
  - 체력 30. 민미 공격(단일·광역·투사체)이 그대로 맞는다. 조준 대상과 웨이브 수에는 들어가지 않는다.
  - 맞을 때: 말랑하게 눌렸다 튕기고, 25% 확률로 조각 1개.
  - 부서질 때: 두 쪽이 갈라져 튀어 나가 굴렀다가 사라진다. 땅콩빵 조각 3~5개, 가끔 금화.
  - 90초 뒤 다른 자리에 다시 생긴다.
- **자원:** `peanut_piece` 땅콩빵 조각. 아이콘은 반쪽 렌더(`Resources/ItemIcons/peanut_piece.png`).

## 하프물범 펫 (`World/PetSeal.cs`)

- **모델:** `blender/build_seal.py`. **처음 받은 하프물범 필통 모델**(`gift-3d-models/src/models.js` createSeal)의 치수와 부품을 그대로 옮겼다.
  - 몸 타원, 눈, 눈썹, 회색 퐁퐁 코, 지퍼, 지느러미 4개(관절 위치·각도 같음).
  - 털은 털결 노멀 맵(`Fur_Normal`)과 광택으로 표현했다.
  - 몸 길이 약 0.8m.
- **애니메이션:** Idle, Walk, Run(배로 통통 갈럼프), Windup, Attack1(몽실 박치기), Attack2(물방울 뿜기), Guard, Dodge, Hit, Death(기절), Happy(빙글 + 짝짝), Eat, Sleep.
- **야생:**
  - 자연(초록) 자리 3곳 + 시작 위치 근처 1마리(`NatureSpawner.testNearStart`)에 나타난다.
  - 집 둘레를 어슬렁거리고 가끔 존다.
  - 가까이 가면 안내: **F 땅콩빵 조각 주기 (n/3)**. 3번 주면 길들여진다. 펫은 한 마리만 둘 수 있다.

### 길들인 뒤

| 기능 | 내용 |
|---|---|
| 따라오기 / 기다려 | G 키. 멀어지면 달려오고, 26m 넘게 떨어지면 곁으로 순간 이동 |
| 전투 보조 | 주인의 조준 대상(없으면 가까운 적)을 공격. 몽실 박치기 4+2(근접), 물방울 뿜기 3+2 ×2(원거리 투사체, 침잠). 위력이 낮아 일방 공격이 주력 |
| 막아서기(대신 합) | 주인을 노리는 적의 예고를 보면 사이로 뛰어든다. 확률은 30% + 친밀도로 최대 70%. 적의 첫 타격 시각(`SkillExecutor.TimeToFirstHit`)에 맞춰 박치기를 시작한다. 막아서는 동안 그 적의 공격은 물범에게 오고(`CombatResolver.Interceptor`), 양쪽 히트박스가 겹치면 합이 된다(합 연출에 물범 이름이 나옴) |
| 응원 | 주인 체력이 30% 아래로 떨어지면 체력 15% 회복(친밀도 80 이상이면 22%). 90초마다 |
| 물어 오기 | 주인에게서 4~14m 떨어진 아이템·금화를 물어 온다 |
| 냄새 맡기 | 45초마다 60m 안의 가장 가까운 땅콩빵 방향(앞·뒤·왼쪽·오른쪽 + 거리)을 알려 준다 |
| 쓰다듬기 · 간식 | F 키. 조각이 있으면 간식(체력 30% 회복, 친밀도 +5), 없으면 쓰다듬기(친밀도 +2) |
| 기절 | 체력 0이면 기절했다가 20초 뒤 절반 체력으로 일어난다. 죽지 않는다 |
| 성장 | 전투로 경험치를 얻는다. 레벨마다 최대 체력 +10, 2레벨마다 코인 최종 위력 +1 |

- **HUD(`UI/PetHUD.cs`):** 왼쪽 위 펫 카드(얼굴, 이름 Lv, 따라오는 중·기다리는 중·기절, 체력, 친밀도 하트 5개, 경험치), 화면 아래 안내, 소식 알림.
  - 미리보기: `tools/pet_mock.py`
- **저장:** `SaveData.pet`. 불러오면 곁에 다시 데려온다.
- **레이어:** 물범은 `Pet` 레이어에 있다. 적 공격은 맞고(막아서기), 민미 공격은 같은 팀이라 맞지 않는다. 장비 화면 카메라에는 찍히지 않는다.

## 집에서 찾은 장비 (`blender/build_home_gear.py`)

민미 모델 공간에서 만들고, 뼈마다 따로 내보내 bindpose로 붙인다(`model = "경로@뼈|경로@뼈"`).

| 이름 | 칸 | 등급 | 효과 | 모양 |
|---|---|---|---|---|
| 이불 로브 | 가슴 | A | 최대 체력 +25, 받는 피해 -8% | 누빔 이불 망토(등·옆) + 두건(머리) |
| 각티슈 방패 | 아티팩트 | B | 가드 피해 감소 +15% | 왼팔 바깥의 꽃무늬 각티슈, 휴지 한 장 |
| 수면 모자 | 머리 | C | 회피 코인 위력 +2 | 남색 고깔 + 접단 + 방울(귀는 위로) |
| 수면 바지 | 다리 | B | 최대 체력 +15, 회피 코인 +1 | 하늘색 체크 반바지 + 고무줄 |
| 털 슬리퍼 | 발 | B | 이동 속도 +10%, 회피 코인 +1 | 분홍 털 슬리퍼 + 방울(양발) |

- **새 능력치:** `EquipStats.guard` / `evadePower` / `moveSpeed`.
  - 가드: `DefenseController.GetDamageMultiplier`
  - 회피 코인: `StartEvade`
  - 이동: `PlayerController`
- **얻는 법:** 적 처치 4%(보스 30%), 땅콩빵 부수기 6%(`HomeGear.Random`). 바로 시험하려면 `Inventory.NewGame`에 한 줄 추가한다.
