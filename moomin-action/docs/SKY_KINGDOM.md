# 천상국(다른 왕국) — 계획 (아직 안 만듦)

사용자가 준 참고 그림: `docs/refs/sky_kingdom/01~09`. **하프물범 성을 먼저 마무리한 뒤** 만들기로 함.

## 정한 것
- 자리: **구름 위에 떠 있는 섬**(마을에서 특별한 방법으로 올라감 — 빛의 계단·비행선 등, 정할 것)
- 영주: Claude 가 제안하기로 함(하늘·빛·구름 테마) — 만들기 전에 사용자에게 보여 줄 것

## 하프물범 성과의 차이
- 하프물범 성 = 고딕(뾰족 아치 · 늑골 천장 · 스테인드글라스) + 하프물범 장식
- 천상국 = 바로크/아르데코(금 몰딩 · 크리스털 · 하늘빛 유리 천장) + 하늘·구름·빛 장식
