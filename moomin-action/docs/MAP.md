# 맵 구조와 확장 규칙

맵은 `blender/build_map.py`가 원본 3D 월드에서 만든다. 결과는 두 가지다.
- `Assets/City/City.fbx` + `Textures/`: Unity용, 최적화 구조
- `exports/City.glb`: 하나로 합친 맵, 월드맵 렌더 같은 도구용

## 최적화 구조 (`City.fbx`)

```
World
├─ Terrain    산(한 덩어리씩) · 언덕·바위(48m 칸) · Ground(평평한 바닥, LOD 없음)
├─ Castle     성(48m 칸)
├─ Town       마을 건물(48m 칸)
├─ Foliage    나무·수풀(48m 칸, LOD1까지만 — 멀면 사라짐)
├─ Collision  칸마다 충돌 메시(화면에는 안 그림, 작은 장식·나무 제외)
├─ Props      ┐
├─ Interiors  ├ 빈 자리: 이후 소품·인테리어를 여기에 넣는다
├─ Decor      ┘
└─ PlayerSpawn
```

- **구역(칸):** 원래 부품(건물 하나, 산 하나) 단위로 칸에 배정한다. 건물이 칸 경계에서 잘리지 않는다. 화면 밖 구역은 그리지 않는다(절두체 컬링).
- **LOD:** 구역마다 `이름_LOD0/1/2`로 내보내면 Unity가 LOD Group을 자동으로 만든다.
  - **LOD0:** 원본 그대로. 가까이서 보이는 모습은 최적화 전과 같다.
  - **건물·성:** LOD1은 작은 장식 덩어리(0.6m 미만: 창틀·등불·울타리 조각)를 빼고 같은 평면을 합친다. LOD2는 2.5m 미만 덩어리를 빼고 평면을 더 크게 합친다. 덩어리 단위로 빼기 때문에 벽에 구멍이 나지 않는다.
  - **산·언덕:** 형태를 유지하며 면을 45% / 15%로 줄인다.
  - **나무·수풀:** LOD1은 작은 수풀을 빼고, 더 멀면 그리지 않는다.
- **전환 거리:** `Editor/MapTools.cs`의 `LodHeights`. 화면에서 차지하는 높이 비율로 정한다.
- 구역별 면 수 결과: `docs/map_optimization.md`

## Unity에서

1. 메뉴 **Moomin ▸ 4. 메인 씬 만들기**를 누르면 맵을 배치하고 아래 규칙을 자동으로 적용한다.
2. 소품이나 인테리어를 넣었으면 메뉴 **Moomin ▸ 맵 정리**를 누른다. 같은 규칙이 다시 적용된다.
3. (선택) 메뉴 **Moomin ▸ 맵 가림 처리 굽기**를 누르면 건물에 가려진 물체를 그리지 않는다. 맵이나 소품을 바꿨으면 다시 굽는다.

| 위치 | 맵 정리 규칙 |
|---|---|
| Terrain · Castle · Town | 정적(배칭·가리개·가려짐·반사), LOD 전환 높이 |
| Foliage | 정적(배칭·가려짐) — 얇아서 가리개로 쓰지 않음 |
| Collision | 메시 충돌체, 렌더러 끔 |
| Props · Interiors · Decor 의 각 자식 | Rigidbody가 있으면 건드리지 않음(움직이는 소품). 아니면 정적으로 설정. 4m 이상이면 가리개로도 씀. 충돌체가 없으면 메시 충돌체를 붙임(0.5m 미만이거나 이름이 `NoCol_`로 시작하면 붙이지 않음). 2m 미만이고 LOD가 없으면 멀면 안 그리는 1단계 LOD를 붙임 |

적의 길찾기(NavMesh)는 게임을 시작할 때 모든 충돌체로 굽는다. 그래서 새 소품의 충돌체도 따로 손대지 않아도 길찾기에 반영된다.

## 새 오브젝트·소품·인테리어를 넣는 규칙 (호환성)

- **단위:** 1 = 1m, Y가 위, 정면은 +Z. Blender에서 만들면 `blender/lib.py`의 FBX 설정(`axis_forward=-Z, axis_up=Y`)을 그대로 쓴다.
- **기준점:** 소품은 바닥 가운데. 회전과 크기를 적용한 뒤 내보낸다.
- **위치:** 고정 소품은 `World/Props`, 장식(깃발·덩굴처럼 충돌이 필요 없는 것)은 `World/Decor` 아래에 두고 이름을 `NoCol_`로 시작한다. 건물 내부는 `World/Interiors/<건물 이름>` 아래에 둔다.
- **LOD:** 직접 LOD를 만들면 `이름_LOD0/1/2` 규칙을 따른다. Unity가 자동으로 묶는다.
- **재질:** 가능하면 맵 재질(`Assets/City/Materials`)을 재사용한다. 같은 재질끼리는 정적 배칭으로 합쳐진다. 새 텍스처는 2048 이하로 한다.
- **충돌:** 복잡한 소품은 단순한 충돌용 메시를 `이름_Collision`으로 함께 넣고, 보이는 메시는 `NoCol_`로 둔다.
- **인테리어(이후 계획):** 건물 안을 따로 씬으로 만들어 문에서 불러오는 방식(Additive Scene)이나, `Interiors` 아래에 두고 플레이어가 들어가면 지붕 구역을 숨기는 방식이 모두 이 구조와 호환된다.
