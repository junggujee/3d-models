# 레벨 시스템 (2026-11-24)

규칙은 `Core/LevelMath.cs` 한 곳에 있다(순수 C#, status_tests로 검증).

## 레벨업 (`Player/Experience.cs`)

- 레벨마다 최대 체력 +12, 공격력 +0.6이 오른다(예전에는 +10, +0.5).
- 레벨이 오르는 순간 체력과 스태미나가 모두 찬다.
- 10레벨마다 칭호가 바뀐다: 초보 → 새싹 → 숙련 → 노련 → 전설의 검사. 칭호는 캐릭터 시트 이름 아래에 보인다.
- 레벨은 `CharacterStats.level`에도 들어간다. 적과 펫도 같은 칸을 쓴다.

## 레벨 차이 → 코인 위력

- 공격할 때 코인마다 상대 레벨과 비교한다. **3레벨 차이마다 코인 위력이 ±1, 최대 ±3**이다. 내가 높으면 +, 낮으면 −이다.
- 앞면일 때 더해지는 코인 위력에만 들어간다. 피해 공식 자체는 그대로다.
- 적도 똑같이 적용받는다. 레벨이 많이 낮은 적은 코인 위력이 낮아 합에서 불리하다.
- 상대는 `SkillExecutor.LevelOpponent()`가 정한다: 적은 쫓는 대상, 민미는 조준 대상, 둘 다 없으면 12m 안 가장 가까운 다른 팀.
- 조준한 적 이름 앞에 레벨이 색으로 보인다. 내가 높으면 초록 "Lv.5 (코인 위력 +1)", 낮으면 빨강이다. 보스바 이름 앞에도 Lv가 붙는다.

## 적 레벨 (`EnemyCombatController.SetLevel`)

- 적 레벨 = 웨이브 + (−1~+1) + 종류 보정 + 보스 +3
  - 종류 보정: 곰 +1, 그린볼런 +1, 고래 +2 (`levelOffset`)
- 레벨마다 체력 +6%, 공격력 +0.5, 처치 경험치 +8%.
- 실제로 얻는 경험치는 레벨 차이에 따라 바뀐다. 적이 높으면 레벨당 +10%, 낮으면 −10%이고, 50%~150% 안에서 정해진다.
