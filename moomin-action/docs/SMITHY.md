## 제작 — 3 × 3 작업대 (`UI/CraftBench.cs` · `ForgeMath.Match`)
- 마인크래프트처럼 **오른쪽 가방 재료를 왼쪽 3 × 3 칸에 모양대로 놓으면** 화살표 오른쪽에 결과가 뜸 → 누르면 제작
  - 재료 클릭 = 손에 듦 · 칸 클릭 = 1개 놓기(같은 칸 다시/우클릭 = 비우기) · 재료 우클릭 = 빈칸 모두 채우기
  - 놓은 재료는 만들 때까지 가방에서 빠지지 않음(남은 개수만 줄어 보임). 남은 재료로 한 번 더 되면 배치가 그대로 남음
  - 모양은 작업대 어디에 놓아도 되고 좌우를 뒤집어도 됨. 모양 없는 제작법은 위치 상관없이 종류·개수만
  - 아래 **제작법 책**: 재료가 있으면 자동으로 놓고, 없으면 흐린 그림으로 모양만 + 모자란 재료 알림
  - 수고비 없음. 이미 가진 무기·열쇠 물건은 다시 못 만듦
- **특별 제작 연출**(`Recipe.showcase`, 레이저 블레이더): 재료가 가운데로 빨려 들어감(0.7초) → 망치 두 번(푸른 불똥 · 화면 흔들림) → 푸른 빛 고리가 퍼짐 → 화면이 어두워지고 무지개빛 빛줄기 속에서 결과가 튀어 오름 + "레이저 블레이더 완성!" + 풍선고래 환호(약 3.4초, 그동안 Esc 로 못 닫음)
- 미리보기 `tools/craft_bench_mock.py` → `previews/craft_bench_mock.png` · `craft_showcase_mock.png` — **CraftBench 배치 숫자를 바꾸면 같이**

| 만드는 것 | 모양(가운데 정렬) | 재료 |
|---|---|---|
| 레이저 블레이더 ★ | `A.B / .C. / B.A` | A 파란 방망이 조각 · B 사골곰뼈 · C 무지개 진주 |
| 땅콩빵 | `PPP / PPP / PPP` | 땅콩빵 조각 9 |
| 꿀바른 땅콩빵 | 모양 없음 | 땅콩빵 + 꿀 |
| 회전 쌍검 | `S.S / DFD / S.S` | 별조각 · 불씨 가루 · 은빛 깃털 |
| 베개 방패 | `SFS / SFS` | 별조각 · 은빛 깃털 |
| 파란 머리띠 | `SFS` | 별조각 · 은빛 깃털 |
| 용궁 진주 반지 | `.S. / SPS / .S.` | 별조각 · 무지개 진주 |
| 진동 부적 | `D / M / D` | 불씨 가루 · 맨두의 진동 코어 |

- 재료 얻는 곳: **사골곰뼈** = 곰곰이 보스(보스 웨이브에 거대한 그림자와 번갈아, 첫 보스가 곰곰이 — 쓰러뜨리면 2개, 문장 `BossEmblem_Bear`) ·
  **무지개 진주** = 고래고래 임금님을 이길 때마다 1개(재대결 포함 — 퀘스트용 royal_pearl 과 별개) · **파란 방망이 조각** = 맨두

## 강화 (`ForgeMath`, +0 ~ +5)
| 단계 | 성공률 | 비용(기준값 ×) | 실패하면 |
|---|---|---|---|
| +1 | 95% | ×1 | 그대로 |
| +2 | 80% | ×2 | 그대로 |
| +3 | 60% | ×4 | 그대로 |
| +4 | 40% | ×7 | **한 단계 하락** |
| +5 | 25% | ×12 | **한 단계 하락** |

- 기준값 = 무기 가격 ÷ 4 (최소 40). 예) 레이저 블레이더(680) → +1 에 170, +5 에 2,040 골드
- **무기는 절대 부서지지 않는다**(풍선고래의 자부심)
- 효과: 단계마다 공격 배율 +8% · 두 단계마다 최종 위력 +1 · 받는 피해 -1.5%
- 저장: `Inventory.enhance`(아이디 → +N) → `Inventory.State.enhance`("아이디=단계") → 저장 슬롯
- 적용: `ApplyWeapon`(공격 배율) · `TotalStats`(최종 위력 · 피해 감소). 이름은 `Inventory.DisplayName` / `ForgeMath.Prefix` 로 "+3 레이저 블레이더"
- 연출: 세 번 두드림(0.55초 간격 — 망치 동작 + 불똥 + 화면 흔들림 + 화면 번쩍) → 성공/실패. 두드리는 중에는 Esc 로 못 닫음
