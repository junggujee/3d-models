# 🦭 하프물범 필통 · ⚔️ 스타 스파크 검 3D 모델 패키지

준우·정우 생일 AR 서프라이즈에 쓴 3D 선물 모델과 애니메이션만 따로 모은 폴더입니다.
AR 프로그램 없이도 다른 곳에서 다시 쓸 수 있습니다.

## Claude에게 넘기는 방법

1. 이 압축 파일(`gift-3d-models.zip`)을 새 대화에 첨부하거나, 프로젝트 폴더에 압축을 풀어 넣으세요.
2. 아래 문장을 복사해서 보내면 됩니다.

> 첨부한 gift-3d-models 폴더의 CLAUDE.md를 먼저 읽어줘. 이 하프물범 필통과 스타 스파크 검 3D 모델(three.js, 애니메이션 포함)을 ________ 에 쓰고 싶어.

   빈칸 예시: "새 생일 카드 웹페이지", "React 프로젝트의 메인 화면", "Unity용 GLB 파일로 변환해서".

`CLAUDE.md`에는 Claude가 바로 작업할 수 있도록 다음 내용을 정리해 두었습니다.
- 사용법과 좌표·크기
- 털·발광·스파크를 만든 방식과 조정할 수 있는 숫자
- 꼭 지켜야 할 조건(검에 글씨 넣지 않기 등)

## 직접 보기
폴더에서 `npx serve .` 또는 `python3 -m http.server`를 실행한 뒤, 브라우저로 아래 주소를 엽니다.
- `http://localhost:3000/demo/index.html` (주소는 실행 결과에 나온 포트를 따르세요): 360° 돌려 보기
- `demo/minimal-scene.html`: 두 모델을 한 장면에 넣은 예제

인터넷 연결이 필요합니다. three.js를 CDN에서 불러옵니다.
