# 🌀 회전 쌍검 광선검 3D 모델

가운데 고리를 쥐고 빙글빙글 돌리는 쌍검 광선검을 코드로 만든 3D 모델입니다.
생일 AR 프로그램과는 별개로, 다른 곳에서 쓰기 위한 패키지입니다.

## 할 수 있는 것
- **테마 3가지**: 실버, 골드, 블루 (상품 사진 3장의 색)
- **🌀 회전**: 선풍기처럼 빠르게 돌고, 빛 잔상과 퍼지는 빛 고리가 생깁니다
- **⚡ 칼날**: 칼날이 쭉 펼쳐지고 접힙니다
- **🎨 24색**: 칼날·LED·번개 색이 함께 바뀝니다
- 칼날을 감는 번개와 손잡이 옆에서 튀는 불꽃이 계속 움직입니다

## Claude에게 넘기는 방법
1. `spin-saber-3d.zip`을 새 대화에 첨부합니다. 프로젝트 폴더에 풀어 넣어도 됩니다.
2. 아래 문장을 복사해서 보내세요.

> 첨부한 spin-saber-3d 폴더의 CLAUDE.md를 먼저 읽어줘. 이 회전 쌍검 광선검 3D 모델(three.js, 애니메이션 포함)을 ________ 에 쓰고 싶어.

하프물범·스파크 검 패키지(`gift-3d-models.zip`)와 함께 첨부하면 세 모델을 한 장면에서 같이 쓸 수도 있습니다.

## 직접 보기
폴더에서 `npx serve .` 또는 `python3 -m http.server`를 실행한 뒤, 브라우저로 `/demo/index.html`을 엽니다.
three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.
